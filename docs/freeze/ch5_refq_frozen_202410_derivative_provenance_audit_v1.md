The DBMS key set is identical: all 690 DBMS_urnform keys are non-null and unique in both files. The local derivative is not byte-identical to the upstream October blob. The 40 blank-to-placeholder ID changes are representation-only under current seed-admission semantics. None of the 32 blank-to-numeric IDs is in the frozen 294 analysis seeds; seven are candidate-only without frozen evidence. repo_created_at is scientifically consumed indirectly for project-age/RQ3 features, but its actual source/API execution record is absent.
